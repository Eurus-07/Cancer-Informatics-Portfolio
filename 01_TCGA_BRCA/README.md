# TCGA Breast Cancer (BRCA) Analysis

## Research Question

How do molecular subtypes of breast cancer differ in gene expression and clinical characteristics?

## Dataset

The Cancer Genome Atlas Breast Invasive Carcinoma (TCGA-BRCA) cohort.

## Objectives

1. Explore the clinical characteristics of TCGA-BRCA patients.
2. Compare gene expression patterns between breast cancer molecular subtypes.
3. Identify differentially expressed genes associated with specific subtypes.
4. Explore the biological pathways represented by these genes.
5. Investigate whether selected molecular features are associated with patient outcomes.

## Analysis Plan

- Clinical data exploration
- RNA-seq data preprocessing
- Exploratory data analysis
- PCA and clustering
- Differential gene expression analysis
- Data visualisation
- Pathway enrichment analysis
- Survival analysis
