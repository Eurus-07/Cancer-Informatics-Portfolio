# Cancer Informatics Portfolio

A portfolio of computational cancer research projects using public genomic and clinical datasets.

## About

This repository documents my development in cancer informatics, combining cancer biology with computational and bioinformatics approaches.

The projects focus on analysing real-world cancer datasets to investigate tumour biology, gene expression, molecular subtypes, biomarkers, and clinically relevant patterns.

## Projects

Analysis of genomic, transcriptomic, and clinical data from The Cancer Genome Atlas (TCGA) Breast Invasive Carcinoma cohort.
